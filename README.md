## ⚡ What I Build

I design and engineer software that runs close to the metal and right at the network edge—with a strict commitment to high throughput, clean architecture, and responsive user interfaces.

### 🛰️ High-Performance Networking & Security Tooling
- **Proxy Protocols & Tunneling**: Advanced VLESS-over-WebSocket, xHTTP configuration engines, and SOCKS5 proxy architectures.
- **Traffic Diagnostics & Optimization**: High-concurrency multi-threaded IP and SNI scanners, speed benchmarks, and Linux TCP kernel tuning.
- **Creator of [V2Leafy](https://github.com/Code-Leafy/V2Leafy) (210+ ★)**: Production-grade FastAPI WebSocket gateway and real-time management dashboard.

### 🤖 Advanced Telegram Bot Engineering (Any Scale & Complexity)
- **Custom End-to-End Solutions**: Architecting complete Telegram ecosystems for any custom use-case requested—no matter how simple or complex.
- **Telegram Mini Apps (TMA)**: Full-stack interactive WebApp frontends embedded seamlessly inside Telegram chats.
- **Automated Commerce & Financial Engines**: Storefront bots with cart systems, checkout flows, crypto/fiat payment processing, live market feeds (gold, currencies, oil), and automated alerts.
- **Serverless & Edge Scalability**: Ultra-low latency deployments running serverless on Cloudflare Workers and event-driven backends with zero operational overhead.

### 🖥️ Systems & Desktop Application Development
- **Cross-Platform Desktop Apps**: Native applications built with **Tauri 2 (Rust + TypeScript)**, delivering minimal binary footprints and near-zero memory consumption.
- **GUI Utilities**: Desktop clients for DNS switching, VPN management engines, and real PTY-backed terminal experiences.
