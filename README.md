# CodeLeafy

Systems and network software developer specializing in high-throughput network tooling, desktop applications, and end-to-end Telegram bot architectures.

[Website](https://code-leafy.github.io/Code-Leafy/) • [GitHub](https://github.com/Code-Leafy) • [Telegram](https://t.me/CodeLeafy)

---

## Core Focus Areas

### Telegram Bot Architecture & Engineering
Full-lifecycle development of custom Telegram bots and Telegram Mini Apps (TMA) across any scale, complexity, or custom requirement:
- Custom interactive bots and bot ecosystems tailored to any user specification
- Telegram Mini Apps (TMA) and web-app interfaces embedded directly in Telegram
- Automated commerce, shopping cart workflows, and multi-tier administrative panels
- Payment gateway integration (cryptocurrency and fiat pipelines)
- Real-time data streams, financial feeds, and automated notification engines
- Serverless edge deployments on Cloudflare Workers and containerized backends

### Network Engineering & Proxy Tooling
- Custom implementations and tooling for VLESS, Trojan, and xHTTP protocols
- High-concurrency, asynchronous multi-threaded scanners for IP and SNI discovery
- Real-time proxy benchmarking, latency measurement, and speed-testing engines
- Linux kernel and TCP performance optimization for VPS infrastructure

### Systems & Desktop Development
- Cross-platform desktop tools built with Tauri (Rust and TypeScript)
- Native system utilities for DNS management, VPN clients, and network controls
- Single-file services and zero-dependency deployments
